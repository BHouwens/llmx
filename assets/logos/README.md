# Model profile logos

- `qwen.jpg` is the Qwen logo shown in the official QwenLM repository README,
  downloaded from `https://qianwen-res.oss-cn-beijing.aliyuncs.com/logo_qwen.jpg`.
- `qwen.png` is the QwenLM GitHub organization avatar, downloaded from
  `https://github.com/QwenLM.png?size=256`.
- `deepseek.png` is a PNG rendering of the official DeepSeek logo SVG from
  `https://github.com/deepseek-ai/DeepSeek-LLM/blob/main/images/logo.svg`.

These are used as model provider identifiers in llmx. The DeepSeek project
publishes brand asset usage guidance in its
[official repository](https://github.com/deepseek-ai/awesome-deepseek-integration/blob/main/docs/_logo%20svg/guidelines.md).
